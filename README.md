# Cyber Security Base 2025, Project I

Very basic note application containing 5 security flaws from OWASP top ten list from 2021 and steps to fix them.

## Installation

Clone the repository:

```bash
$ git clone https://github.com/kivistoilkka/cyber-security-project-i-25.git
$ cd cyber-security-project-i-25
```

Create virtual environment and install dependencies:

```bash
$ python3 -m venv venv
$ source venv/bin/activate
(venv) $ pip install -r requirements.txt
```

Start up the application:

```bash
(venv) $ python3 src/manage.py runserver
```

The server is now running in http://127.0.0.1:8000/. Quit the server with Ctrl+C.

To exit virtual environment:

```bash
(venv) $ deactivate
$
```
